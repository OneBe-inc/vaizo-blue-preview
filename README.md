# VAIZO Blue Design Preview

会話内で承認されたブルー版（v05）のTOPをHTML/CSS/JavaScriptで実装した確認用ページです。OneBe-incのGitHub Pagesで配信します。VAIZO本番サイトの変更ではありません。

## 起動

`node serve.cjs` → http://127.0.0.1:4187/

依存ライブラリ不要。GitHub Pagesはmainのルートを使用します。

## 実装

- FVは100svh。PCとスマートフォンで主要コピー・説明・CTAを画面内に配置します。
- 小さな画面では角丸ヘッダーのMENUからナビゲーションを開閉できます。
- お知らせ、会社紹介、事業紹介、ストーリー、メッセージ、フッターをHTMLの文字とリンクで構成。
- 4つの取り組みカードを開閉可能。紹介動画の枠は未設定のため、再生ボタンから紹介モーダルを開きます。
- 実在する問い合わせフォームへのリンクは https://vaizo.jp/contact/ 。デモ内では個人情報を収集しません。
- デザイン確認用のためnoindex。コーポレート情報や写真を確定する前のデモです。

## 素材

写真は会話で生成した画像案から切り出したものです。実在するVAIZOの顧客・スタッフ・成果を示すものではありません。参考サイトから写真・イラストを流用していません。

ロゴはOneBe管理下の既存素材 `OneBe_Corporateヒートマップ_20261024/site/public/assets/vaizo-brand-logo.webp` にあるVAIZOロゴを使用。余白をトリミングして縦横比を維持しています。生成画像の疑似ロゴはヘッダーに使用しません。

元デザインは `VAIZO_v05_FV_ブルー.png`、`VAIZO_v05_01_ブルー.png`、`VAIZO_v05_02_ブルー.png`。レスポンシブ対応と画面高に合わせるため、すべての画面で画像原稿と完全なピクセル一致を保証するものではありません。

## 性能設計

通常サイト。本文・CTAは初回HTMLで表示。JavaScriptはメニュー、カード開閉、dialogのみ。アニメーション、常時描画、動画埋め込み、トラッキングはなし。主要4枚の写真は初回読み込み、下部画像はlazy。ロゴおよび配信用写真はWebP。動作軽減設定ではスムーズスクロールを無効化。

初期予算：JS 10KiB、CSS 35KiB、FV写真200KiB、フォントは必要ウェイトのみGoogle Fonts経由。全体24画像で約450KiB。実測のWeb VitalsはQA記録参照。実ユーザーINP/LCP/CLS未取得。

## 未確定・制約

- 動画・ニュース・メッセージはデザイン確認用の内容。実運用の動画未接続。
- CTA以外の詳細リンクは既存のVAIZO公式ページへ移動します。
- 画像原稿の色・レイアウトに近づけていますが、ブラウザーやフォント描画による差があります。
